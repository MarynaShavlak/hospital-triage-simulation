# Документація дослідження

Це повний, нічого не втрачений виклад оригінального дослідження,
розбитий на тематичні розділи.
Кожен розділ містить **пояснення**, **код**, **реальні результати його виконання**
та **візуалізації** (графіки з каталогу [`../figures/`](../figures)) — у тій самій
послідовності, у якій велося дослідження.

> 23 графіки відтворюються скриптом [`scripts/save_figures.py`](../scripts/save_figures.py)
> з того самого коду й даних, що й оригінальне дослідження (де вони показувалися
> інлайн через `plt.show()`, без збереження у файли). Числа в розділах відповідають
> seed=42, де не зазначено інше.

> **Код у доках ≠ код пакета.** Розділи дослівно викладають оригінальне дослідження (навчальна, «розгорнута» форма). Натомість [`src/triage_sim`](../src/triage_sim) — це **чистіша реалізація з ідентичною поведінкою**: спільний драйвер + політики черги, єдине джерело розподілів, тести-звірки. Тому inline-код у розділах подеколи структурно відрізняється від пакета (там, де це важливо, стоїть «Примітка щодо реалізації»).

## Як читати

Розділи впорядковані як наратив — від простого до складного. Найкоротший шлях до
суті: **00 → 06 → 07 → 13 → 15**. Повний шлях — підряд від 00 до 15.
